ATLAS V98.0.0 — Safe Customer Messaging + Domain-Independent SEO

Source baseline
- Continuation of Atlas V90 through the existing V91–V96 customer-agent, automation, service desk, SLA and authority work.
- V97 added no-domain-safe marketing SEO generation and preview indexing controls.
- V98 adds deterministic tenant-bound template rendering and the message-studio sample preview.
- Platform-global authority remains exclusive to the configured, verified Khan account. Company owners/admins remain tenant-scoped.

V98 implementation
- Added renderMessageTemplateVersion() for immutable, checksummed, exact-tenant templates. It returns a deterministic draft only; it does not deliver or persist a message.
- Added allowlisted business-data variables, safe own-property reads, HTML text escaping, a small email markup/HTTPS-link allowlist, header-injection rejection and fail-closed missing-data outcomes.
- Added a laptop-first Message Studio preview, clearly marked as sample data and not sent.
- Extended GHL/n8n benchmark findings and CI checks; preserved existing business-hours SLA and verified single-owner security invariants.

V97 indexing behavior
- Default `node scripts/build-site.mjs` produces a preview with noindex/nofollow and deny-all robots.txt; no canonical or sitemap is invented.
- Public mode requires an explicit real HTTPS origin, emits canonical/social metadata and visible-content-matched JSON-LD, and writes a one-page sitemap. The sample /app/ remains noindex and is excluded.
- No public Atlas domain exists yet; do not deploy public mode until a real domain and HTTPS are configured.
